# ShopSphere – Product Service

## 1. Overview
The Product Service manages the product catalogue of the ShopSphere e-commerce application.

It is an independently developed microservice responsible for maintaining product information and exposing REST APIs to other services.

## 2. Business Responsibilities
- Create new products.
- Retrieve product details.
- List available products.
- Update product information.
- Delete products.
- Provide product information to the Order Service.

## 3. Technology Stack
- Python 3.13
- FastAPI
- PostgreSQL
- SQLAlchemy
- Docker
- Kubernetes
